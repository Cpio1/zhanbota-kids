# Детский сад «Жанбота» — лендинг

Next.js 16 · TypeScript · Tailwind CSS 4 · Framer Motion · Lucide. Полностью статический сайт (`output: "export"`).
Двуязычный (казахский по умолчанию / русский), всегда светлый, с фирменным маскотом-верблюжонком.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # статический сайт в папке out/
```

## Где что менять

| Что | Файл |
|---|---|
| Контакты, адрес, БИН, цена, координаты | `lib/site.ts` |
| Группы (названия, возраст) | `config/groups.ts` |
| Документы (PDF / Google Drive) | `config/documents.ts` (PDF кладите в `public/docs/`) |
| Все тексты KZ / RU | `locales/dictionary.ts` |
| Фото и видео первого экрана, фото «О нас» | `public/images/hero/` (см. README там) |
| Галерея | `public/images/gallery/` |
| PNG-маскоты | `public/images/mascots/` (см. README там) |

Медиафайлы находятся автоматически при сборке: положите файл и пересоберите сайт, код менять не нужно.

## Публикация

### GitHub Pages
1. Загрузите проект в репозиторий GitHub (ветка `main`).
2. Settings → Pages → Source: **GitHub Actions**.
3. Каждый push в `main` запускает `.github/workflows/deploy.yml`, который собирает и публикует сайт.
   Подпапка репозитория (`/<имя-репозитория>`) подставляется в `basePath` автоматически.

**Собственный домен:** укажите его в Settings → Pages → Custom domain, а также добавьте переменную репозитория
`CUSTOM_DOMAIN` (Settings → Secrets and variables → Actions → Variables) — workflow запишет файл `CNAME`.
С подключённым доменом сайт собирается в корне (`basePath` = "").

### Vercel
Импортируйте репозиторий — настройки уже в `vercel.json`. Переменные окружения не нужны.

### Переменные окружения (необязательно)
| Переменная | Назначение |
|---|---|
| `NEXT_PUBLIC_BASE_PATH` | Ручная настройка подпапки, например `/zhanbota` |
| `NEXT_PUBLIC_SITE_URL` | Полный адрес сайта (с подпапкой, если она есть) для Open Graph, например `https://zhanbota.kz` |

## Важно
- Язык меняется только переключателем KZ/RU и сохраняется в `localStorage`; язык браузера и система не учитываются.
- Тёмная тема отключена (`color-scheme: only light`, без `dark:`-классов).
- Карта — OpenStreetMap (без ключей API); кнопки ведут в 2GIS по координатам. ID организации в 2GIS не используется.
- В разделах нет выдуманных данных: названия групп, возраст, меню и документы добавляются через конфигурационные файлы.
