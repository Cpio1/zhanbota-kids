# Маскоты (PNG с прозрачным фоном)

Положите сюда PNG-файлы с этими именами. Каждый файл автоматически заменит временный SVG после следующей сборки:

| Файл            | Раздел     | Поза                                   |
|-----------------|------------|----------------------------------------|
| `hero.png`      | Главная    | верблюжонок приветствует посетителей   |
| `about.png`     | О нас      | машет лапкой                           |
| `groups.png`    | Группы     | играет с кубиками                      |
| `nutrition.png` | Питание    | держит тарелку с фруктами              |
| `gallery.png`   | Галерея    | держит фотоаппарат                     |
| `documents.png` | Документы  | читает книгу                           |
| `contacts.png`  | Контакты   | держит телефон / показывает дорогу     |

Рекомендуется квадрат примерно 600×660 px (пропорции 200:220), до 200 КБ.
