# Главный экран

- `main-page.png` (или .jpg/.webp) — фотография детского сада на первом экране.
- `main-page2.mp4` (или .webm) — дополнительное видео. Если оно есть, на первом экране показывается видео
  (без звука, по правилам браузеров) с кнопкой включения/выключения звука; `main-page.png` становится обложкой видео.
- `about.jpg` (или .png/.webp) — фотография для раздела «О нас».
